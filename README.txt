Kalau format fotonya bukan .jpg (misalnya .png atau .jpeg), buka file
gallery.js, cari baris PHOTOS di paling atas, lalu sesuaikan
ekstensinya di sana.

Kalau ada nomor yang belum diisi fotonya, halaman gallery tetap
berjalan normal — slot itu otomatis diganti dengan placeholder lembut
bertanda 🤍, tidak akan error.

Untuk hasil terbaik saat foto diunduh sebagai kartu kenangan (fitur
tombol "Unduh" di gallery.html), pakai foto dengan orientasi potret
atau persegi, resolusi minimal sekitar 800x1000px.
